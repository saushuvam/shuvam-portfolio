# Shuvam Sau — Recruiter Portfolio

A responsive React + Vite portfolio built from the uploaded resume.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production site is generated in `dist/`.

## Deploy

### Vercel
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`.
5. Output directory: `dist`.

### Netlify
Build command: `npm run build`  
Publish directory: `dist`

The included `public/Resume-Shuvam-Sau.pdf` powers the Resume / Download Resume buttons.
