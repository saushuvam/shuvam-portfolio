## 🚀 Featured Project

### CodeSense AI — AI-Powered Code Review Platform

A full-stack AI code review application built using React, Node.js, Express, Google Gemini API, Redis, Docker, and the GitHub REST API.

### Key Features

* 🤖 AI-powered code reviews using Google's Gemini API
* 🔗 Review pasted code, GitHub repositories, and pull request diffs
* ⚡ Real-time streaming feedback
* 🚀 Redis caching using SHA-256 content hashing
* 🛡️ Fail-open caching design for improved reliability
* 🧪 44 automated tests using Jest and Vitest
* 🔄 GitHub Actions CI pipeline
* 🐳 Docker and docker-compose based development environment
* 🔌 GitHub REST API integration

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/saushuvam/shuvam-portfolio.git
cd shuvam-portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

### 4. Create a production build

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```
